# JShell 使用说明

JShell 是一款本地优先的 SSH / 终端管理工作台：没有账号体系、没有云端依赖，所有主机配置与会话凭据都保存在你自己的电脑上。

## 一、启动与首次使用
1. 双击打开 JShell。首次启动会创建本地数据目录（见文末「数据与日志」）。
2. 主界面左侧是主机列表，右侧是标签页与终端区域。
3. 点击「本地终端」或按 `⌘/Ctrl + T`，直接打开系统默认 shell（macOS 为 zsh/bash，Windows 为 cmd / PowerShell）。
4. 点击「新建主机」或按 `⌘/Ctrl + N`，填写主机地址、端口、用户名与认证方式后保存并连接。

> **选对安装包（Apple Silicon 用户）**：M 系列芯片请下载文件名带 `arm64` 的包。
> 装成 `x64` 会通过 Rosetta 转译运行，实测启动从 0.4 秒变成 8.8 秒、终端滚动也会发涩。
> 若不确定，看「关于」或日志首行：出现「正在 Apple Silicon 上通过 Rosetta 转译运行」就是装错架构了。

## 二、连接主机
支持三种认证方式：

- **密码**：口令经系统安全存储加密后保存在本地；
- **私钥**：选择私钥文件，可填写 passphrase；路径支持 `~/.ssh/id_ed25519`（Windows 也支持 `%USERPROFILE%\.ssh\...`）；
- **SSH 代理**：macOS/Linux 读取 `SSH_AUTH_SOCK`，Windows 读取 OpenSSH Agent 命名管道，适合已经把密钥交给系统代理的用户。

首次连接采用 TOFU（首次信任）策略记录主机指纹；指纹变化时会弹窗对比新旧 SHA256，确认后才写入新指纹。

## 三、分屏与拖拽吸附
- `⌘/Ctrl + D` 向右分屏，`⌘/Ctrl + Shift + D` 向下分屏，`⌘/Ctrl + Shift + W` 关闭当前分屏；
- `⌘/Ctrl + Alt + ←/→` 在分屏之间切换；
- 把标签页拖到任意分屏的**左 / 右 / 上 / 下边缘**，松手即把整个终端并入该分屏；
- 分屏标题栏也可以拖动，用于在同一标签内重新排列。

## 四、文件面板
按 `⌘/Ctrl + E` 切换终端 / 文件面板。SSH 会话可浏览远端目录、上传（含目录）、多选下载、取消传输、新建目录、重命名与递归删除；
本地终端可浏览本机目录、新建、重命名、移入回收站与在系统中定位。

工具栏的地址栏可直接粘贴路径回车跳转（支持 `~` 与相对路径；`⌘/Ctrl + L` 聚焦，`Esc` 还原）。

目录树在**左侧栏底部**，和主机列表同列：

- 自动跟随终端当前工作目录：在终端里 `cd` 后目录树实时刷新，注入无任何登录输出；
  可在「设置 → 文件与同步 → 目录树自动跟随终端目录」里关闭（关闭后目录树改为手动双击浏览）；
- 双击目录进入、双击文本文件打开，点「上一级」返回、「定位当前目录」一键回到终端所在目录；
- 切换标签 / 分屏自动换成对应会话的目录，多会话互不干扰；选中本地终端时自动隐藏；
- 目录不存在或没有访问权限时会在树里给出提示，不会悄悄回到 /root；
- 拖动上边缘调高度，点标题前的箭头可整块收起。

双击文本文件会用内置编辑器打开，可直接修改并按 `⌘/Ctrl + S` 保存（保存是「先写临时文件再原子替换」，失败不破坏原文件）。
二进制文件、以及超过 2 MB 的文件会提示改用下载后本地编辑。

传输采用「先写临时文件、成功后再原子替换」的方式：中途失败不会破坏目标位置已有的文件。

## 五、复制粘贴与目录树
- 终端里复制 / 粘贴用 `⌘/Ctrl + C`、`⌘/Ctrl + V`（Windows/Linux 复制用 `Ctrl+Shift+C`，`Ctrl+C` 保留为中断信号）；
  有选区时复制选区，否则粘贴剪贴板内容；输入框里仍是系统默认的复制粘贴。
- 目录树见上文「文件面板」小节的说明，跟随终端当前目录实时刷新。

## 六、连接测试与标签恢复
- 新建 / 编辑主机时，点弹窗左下角「测试连接」可先验证地址、端口、账号与口令；结果直接在弹窗内提示，不需要先保存。
- `⌘/Ctrl + Shift + T` 重开最近关闭的标签时，若该会话已结束，会在原位自动、静默重连；只有重连失败才会弹出错误提示。
- 主机按分组折叠：点分组名展开/折叠，顶部「全部展开 / 全部折叠」一键操作；右键主机可「克隆配置」复制一份再改。
- 侧边栏「本机」分组可在「设置 → 外观」里整体关闭；只想留 zsh 的话，把鼠标移到某个 shell 上点「隐藏」，
  或在「设置 → 终端 → 侧边栏显示哪些本机终端」里取消勾选，随时可全部恢复。
- 主机右键可打开 / 编辑 / 复制地址 / 删除；删除按钮与二次确认可在「设置 → 主机与连接」关闭。
- **弹窗可以拖着走**：按住标题栏拖到任意位置（新建主机、文件传输、配置包都一样），
  填表时想边看终端边填，窗口挡着就拖开。拖不出屏幕——至少留一条边可见
- **点空白处不会关掉弹窗**：以前点一下遮罩就整个消失，填了一半的表单直接没了。
  现在只有「关闭」按钮和 **Esc** 能关；文件传输在传输进行中，Esc 也不会关
- **标签色支持自定义**：色板右侧那个渐变色圆点是取色器，点开用系统调色板选任意颜色；
  当前色不在预设里时，这个圆点会显示成你选的颜色并高亮

## 七、文件传输（rsync）
标题栏「同步」随时可用（不依赖某个会话），打开向导后四步：方向 → 源与目标 → 选项 → 执行。

第二步会自动检测远端是否装了 rsync：没有安装会直接给出 `apt install rsync` / `yum install rsync` 提示，
不必等到执行页才发现。

- 方向支持「本机 → 服务器」「服务器 → 本机」「服务器 → 服务器」；
- 服务器之间经本机中转（先下载到临时目录再上传），两段都可断点续传，完成后自动清理；
- 默认开启压缩与断点续传，可设置排除规则、是否删除目标多余文件、失败重试次数（0–5）；
- 执行页显示阶段、百分比、已传输大小、速度与剩余时间；失败可点「重试」，已传输部分保留。

> 需要本机与远端都安装 rsync。macOS 自带 2.6.9 可用，但没有整体百分比；安装 3.1+（`brew install rsync`）后可显示百分比与剩余时间。

**Windows 安装 cwRsync（详细步骤）**

cwRsync 是 Windows 上最常用的 rsync 发行版，自带 `rsync.exe` 和 `ssh.exe`。

1. **下载**：访问 [cwrsync.com](https://www.itefix.net/cwrsync) 下载免费版（cwRsync Free），
   或用 Chocolatey：`choco install rsync`。
2. **解压**：将压缩包解压到任意目录，例如 `C:\cwRsync`。
3. **加入 PATH**：把 `C:\cwRsync\bin`（含 `rsync.exe` 和 `ssh.exe`）添加到系统环境变量 `Path`。
   - 右键「此电脑」→ 属性 → 高级系统设置 → 环境变量 → 系统变量 → Path → 编辑 → 新建
4. **验证**：打开**新的** cmd 或 PowerShell（旧窗口不会刷新 PATH），运行：
   ```
   rsync --version
   ssh -V
   ```
   两条都有输出即安装成功。
5. **重启 JShell**：让 JShell 读取新的 PATH。

> **常见问题**：
> - `ssh --version` 报 `unknown option` 是正常的——Windows OpenSSH 用 `-V` 而非 `--version`。
> - 如果 JShell 仍提示「找不到 ssh」，检查 `C:\Windows\System32\OpenSSH\ssh.exe` 是否存在（Windows 10+ 自带）。
> - cwRsync 的 `ssh.exe` 与 Windows OpenSSH 的 `ssh.exe` 可能共存，PATH 中靠前的优先。

## 八、终端搜索与右键菜单
- `⌘/Ctrl + F` 打开搜索条，输入即增量匹配，`Enter` / `Shift + Enter` 跳转；
- 右键终端可复制、粘贴、全选、搜索、清屏、分屏或关闭。

## 九、系统集成
设置 → 系统集成中可以调整：

| 选项 | 说明 |
| --- | --- |
| 开机自动启动 | macOS 登记为登录项，Windows 写入当前用户启动项；无需管理员权限 |
| 启动后仅驻留托盘 | 启动时不打开主窗口，只在菜单栏 / 任务栏托盘显示图标 |
| 关闭窗口时最小化到托盘 | 关闭窗口不退出，SSH 会话在后台继续运行；从托盘菜单「退出 JShell」才真正退出 |
| 发送系统通知 | 会话异常断开、文件传输失败时提醒；应用窗口处于焦点时不打扰 |

> 便携版更换解压目录后，请重新开关一次「开机自动启动」，让系统登记的路径同步更新。

## 十、便携版
便携版不会向系统用户目录写任何数据：

- **macOS**：解压 `JShell-<版本>-<架构>-portable.zip`，得到 `JShell.app`、`jshell-portable.marker` 与说明文件；数据保存在同级的 `JShell-Data` 目录。
- **Windows**：直接运行 `JShell-<版本>-x64-portable.exe`，数据保存在该 exe 同级的 `JShell-Data` 目录。

首次打开未签名包的提示：

- macOS：右键点击 `JShell.app` → 打开；或在终端执行 `xattr -dr com.apple.quarantine JShell.app`。
- Windows：SmartScreen 提示时点击「更多信息」→「仍要运行」。

## 十一、数据与日志
- 安装版数据目录：macOS 为 `~/Library/Application Support/JShell`，Windows 为 `%APPDATA%\JShell`；
- 便携版数据目录：程序目录下的 `JShell-Data`；
- 日志：数据目录下的 `logs/jshell-YYYY-MM-DD.log`，只记录运行状态与错误，不记录口令与终端输出；
- 设置 → 关于 中可直接打开数据目录与日志目录。

## 十二、配置包（跨设备统一配置）
设置 →「文件与配置」→「生成 / 导入配置包…」。配置包是一个普通文件，放哪儿都行，不需要注册账号。

**什么时候用哪个**：

| 需求 | 用哪个 |
| --- | --- |
| 把本机的主机/设置/片段搬到另一台电脑 | **配置包**：生成 → 拷过去 → 导入 |
| 多台机器长期保持一致 | **自动同步**（配置包页签第三项）：指定一个共享位置，自己来回同步 |
| 在本机和服务器之间传文件 | 标题栏「**文件传输**」 |

配置包默认包含主机与分组、命令片段、转发设置、端口转发规则，加密默认开启（口令只输一次，可点「显示」确认）。

- **保存到哪里**（三选一）：
  - **保存到文件…**：存到桌面、U 盘、外置磁盘、局域网共享、任意已挂载的网盘目录；
  - **网盘**：直接列出本机检测到的 iCloud / OneDrive / Dropbox / Google 云端硬盘 /
    坚果云 / 百度网盘 / Nextcloud，选一个存进去；
  - **复制到剪贴板**：临时在两台设备之间传递，直接粘贴进备忘录或聊天窗口即可。

  > 想让它**长期**跟着多台机器一致，用「自动同步」页签——它会自己把配置写进网盘目录，
  > 不用你手动搬文件。

- **包含内容**：主机与分组、命令片段、偏好设置、端口转发默认勾选；
  主机指纹默认**不**同步（信任应由每台设备自己确认）；密码与私钥口令默认**不**同步。
  这一栏默认收起，标题行会直接写明「已选 4 项：…」，需要调整时点开即可。

### 自动同步的判定规则

**破坏性的事交给人决定**，程序不会自己替你在两台设备之间做选择。

| 同步位置 | 本机 | 口令 | 会怎么做 |
| --- | --- | --- | --- |
| 没有文件 | 任意 | 任意 | 写一份上去（同步位置由本机创建） |
| 有文件·能解开 | **空的** | 一致 | 用云端的内容填充本机（主机/片段/转发规则都没有才算空） |
| 有文件·能解开 | 有内容 | 一致 | 逐条合并；会覆盖本机较新改动时先暂停，等你确认 |
| 有文件·**解不开** | 任意 | **不一致** | **停下来问你**，本机和云端都不动 |
| 有文件·明文 | 有内容 | 本机有口令 | **先问一句**：同步后云端会变成密文，对方设备需要同样的口令才能读取 |

「停下来问你」时面板上会出现这几条：

- **输入云端口令** → 用它解开云端的包并合并到本机，同时把这个口令记为本机口令（两台从此一致）
- **用本机覆盖云端** → 二次确认后执行（云端原内容会丢失）
- **暂不处理** → 保持现状，本机和云端都不动

### 自动同步的三种通道

| 通道 | 说明 |
| --- | --- |
| **网盘** | 放在本机网盘目录里，靠网盘客户端自己同步。目录是**自动探测**的：iCloud / OneDrive / Dropbox / Google 云端硬盘 / 坚果云 / 百度网盘 / Nextcloud，外加 macOS 的 `~/Library/CloudStorage` 扫描。只有一个时直接选中；多个时优先用你上次选过的，再按最近活跃排序。**探测不到的（自建网盘、NAS / 共享盘、U 盘、装在非默认路径的客户端）用「＋ 添加同步路径」手动加一条**，可以随时改名或删除。 |
| **SFTP** | 放在你自己的服务器上，走已保存的 SSH 主机 + 远端目录。 |
| **WebDAV** | 走 WebDAV 协议（坚果云、Nextcloud、群晖等常用），填完整地址即可。 |

程序在这个位置维护一个**固定文件名**的文件：`<目录>/JShell/jshell-auto.jshellsync`
（WebDAV 则是 `<你填的地址>/jshell-auto.jshellsync`）。反复同步不会堆出一堆副本。

> **注意**：这个文件和「配置包」没有关系。你手动导出的包（自己命名的那种），
> 自动同步不会去读它；反过来自动同步维护的文件也不会出现在你手动保存的目录里。

**「立即同步」到底做了什么**：用当前配置**重新组一份包**写回同步位置，
同时把同步位置的内容拉回来逐条比对。本机配置没变化时会提示
「已比对：同步位置与本机内容一致，没有变化」——这是正常的，不是没生效。
- **加密**：建议设置口令。加密后云盘里只有密文，口令不会被保存，忘记口令文件就没法恢复。
  勾选「密码与私钥口令」时会强制要求设置口令。
- **导入**：另一台设备上选同一个文件 → 加密包先输入口令「解读」→ 看到来源设备、条目数量，
  随后**自动做一次覆盖前检测**，列出「新增 / 覆盖 / 删除 / 不变」清单。
- **检测里的风险项**（标红）：
  - `本机较新`：这条记录本机改得更晚，导入后会被同步包里的版本覆盖；
  - `删除`：仅替换模式下出现，表示本机独有条目会消失。
  有风险项时必须点确认才会继续，导入前会自动备份到 `data/backups/`，可随时找回。
- **三种导入方式**（可切换，切换后检测结果即时重算）：
  - **覆盖本机**（默认）：包里同一条记录直接覆盖本机，本机独有的主机与片段保留；
  - **合并**：比较更新时间，较新的胜出，本机较新则不动；
  - **替换本机**：包里带的分区整体覆盖，本机独有条目会被删除（需二次确认）。
- **自动同步**（面板第三个页签）：选定一个目录后，应用会把同一个同步包固定写在
  `<目录>/JShell/jshell-auto.jshellsync`，本机改动约 1.5 秒后自动写回，别的设备改动同步到本机后自动拉取。
  - 「本机改动后写回」「远端变化后拉取」可以只开一个；手动点「立即同步」才两个方向各做一次。
  - 默认开启「遇到风险先暂停」：远端会覆盖本机较新的改动、或会删除本机独有条目时不动手，
    状态栏给出摘要，可以一键「按远端覆盖本机」或转去手动检查。
  - 探测不到云盘时用「选择文件夹…」指定任意目录（网络共享、加密盘、U 盘均可）。
  - 也可以把「同步位置」切成 **SFTP 自有服务器**：选一台已保存的主机、填远端目录
    （如 `~/jshell`，不存在会自动创建），同步包直接推到自己服务器，不经过任何第三方。
    面板里的「测试连接」会连一次、建目录、写删探针文件，失败时显示原始错误。
  - 第三种是 **WebDAV**（Nextcloud / 坚果云 / 群晖等）：填目录地址、用户名、密码即可，
    只接受 https（本机地址除外）；会先尝试创建目录，再写入同步包。
  - 三种位置都有「测试连接」，先在面板里点一下再开自动同步，比事后看错误容易排。
  - **删除不会跟着同步**：在一台设备上删掉主机/片段，其它设备不会跟着删，对方下次推送还会把它带回来。
    想让别处也删掉，用「替换本机」导入一份已经删干净的包（导入前自动备份）。
  - 自动同步需要读写同一份加密包，口令保存在本机系统安全存储里，不写进包、也不会回显。
- 窗口尺寸、本机 shell 路径、开机自启等**设备私有**项不会被同步，换设备不会打乱本机布局。

## 断线之后

连接断开时，终端里会弹出一张卡片，而不是挤在底部的横条：

| 情况 | 会怎么做 |
| --- | --- |
| **网络断开 / 超时** | 自动重连：1 秒 → 2 秒 → 4 秒 → 8 秒 → 8 秒，最多 5 次 |
| **你自己敲了 `exit` 或关掉终端** | **不重连**，只显示「会话已退出」，按 Enter 才重新打开 |
| **认证失败**（口令/密钥不对） | 不重连，提示检查口令或密钥 |
| **主机指纹变了** | 不重连，需要先处理指纹 |

不管哪种情况，**按 Enter** 都能立刻重连（不用去点按钮，也不限制鼠标位置）。
卡片上也保留「重新连接」「关闭」两个按钮。

### 保活：避免空闲终端被服务器掐断

很多 sshd 配了 `ClientAliveInterval`，长时间没输入就会把连接断掉；中间的 NAT、
路由器也会让空闲连接的表项过期。表现是「挂着没动，回来一敲就断了」。

JShell 默认开启保活：**每 60 秒发一次，连续 3 次没有回应判定连接已断**（约 3 分钟），
随后按上面的规则处理——网络类原因会自动重连。

- 走的是 SSH 协议层的保活请求（`keepalive@openssh.com`），**不往终端写任何字符**：
  不会污染输入、不会进 shell 历史，也不会打断 vim / less 这类全屏程序
- 只对 SSH 会话生效，本地终端没有这个概念
- 在「设置 → 主机与连接 → 连接保活」里可以关闭，或改间隔（10–300 秒）与判定次数（1–10）
- 改过设置后仅对**新建或重连**的会话生效（已连着的会话沿用建立时的参数）

> 一个附带好处：保活能主动发现「已经断了但本地还不知道」的情况
> （笔记本合盖、切 Wi-Fi、NAT 超时）。没有保活时，往往要等你敲命令的那一刻才发现连接早没了。


## 命令片段

侧边栏或 `⌘/Ctrl + B` 打开。每条片段有三个动作：

| 动作 | 效果 |
| --- | --- |
| 点击片段 | 把命令**填入当前聚焦的会话**并聚焦终端，**不自动执行**——避免误触，也方便你改完参数再回车 |
| 复制按钮 | 把命令复制到**剪贴板** |
| 编辑按钮 | 改名称、命令内容、触发词 |
| 删除按钮 | 删掉这条片段 |

### 触发词：像 alias 一样补全

给片段填一个**触发词**（如 `gps`），在终端里输入它，终端左下角会提示
「gps → push　Tab 补全」，按 **Tab** 就把整行替换成完整命令
（`gps` → `git push`）。补全只改文本、**不替你回车**，命令要不要执行你自己决定。

- 提示条在敲下键的瞬间就出现，不用等远端回显（SSH 连接下也不迟钝）
- 触发词可以只输入一部分（`gp` 也能命中 `gps`）
- 没填触发词时，输入命令本身的前缀也会提示补全
- 多个片段同时命中时，取触发词最长的那条
- 触发词后面接空格加参数也会一起补上（`gps --force` → `git push --force`）

| `⌘/Ctrl + B` | 展开 / 收起命令片段 |
| `⌘/Ctrl + ,` | 打开设置 |

所有快捷键都可以在「设置 → 快捷键」中点击后重新录制。
