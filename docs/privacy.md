# JShell 隐私说明

生效日期：2026-10-23
适用范围：JShell 桌面客户端（macOS / Windows 安装版与便携版）

## 一、核心结论

JShell 是**纯本地客户端**：

- 不要求注册账号，不接入任何云端服务；
- **默认不采集、不上报任何使用数据**：没有埋点、没有崩溃上报、没有设备指纹、没有广告标识；
- 应用只在两种情况下访问网络：
  1. 你主动发起 SSH / SFTP 连接时，与目标主机通信；
  2. 公开下载渠道下，你点击「检查更新」时读取版本清单（内部渠道不发起该请求）。

## 二、本地保存的数据

| 数据 | 位置 | 说明 |
| --- | --- | --- |
| 主机配置（名称、地址、端口、用户名、认证方式、私钥路径） | 数据目录 `data/state.json` | 明文 JSON，便于备份与迁移 |
| 密码、私钥口令 | 数据目录 `data/secrets.json` | 经系统安全存储加密：macOS 钥匙串 / Windows DPAPI；系统不提供加密能力时降级为弱编码并在界面提示 |
| 最近一次的分屏布局 | 数据目录 `data/layout.json` | 只保存「怎么连」，不保存终端内容 |
| 运行日志 | 数据目录 `logs/` | 仅运行状态与错误信息，不含口令、私钥内容与终端输出 |
| 界面偏好 | 数据目录 `data/state.json` | 主题、字号、快捷键等 |

便携版的所有数据都写在程序目录下的 `JShell-Data`，不会写入系统用户目录。

## 三、网络行为

| 场景 | 是否联网 | 发送内容 |
| --- | --- | --- |
| 打开应用 | 否 | — |
| 本地终端 | 否 | — |
| SSH / SFTP 连接 | 是（仅与目标主机） | 标准 SSH 协议数据 |
| 检查更新（内部渠道） | 否 | — |
| 检查更新（公开渠道） | 是（仅在你点击时） | `GET <更新地址>/latest.json`，只带 `Accept: application/json`，不带任何标识 |
| 导出 / 导入同步包 | **否** | 只读写你选定的本地文件，不调用任何云服务 API |

应用不接入第三方统计 SDK，也不使用远程配置。

## 四、配置同步（可选，默认不使用）

「数据共享」功能用于把主机、片段、偏好设置迁移到另一台设备，行为边界如下：

- **默认完全被动**：只有你点击「生成同步包」时，应用才会把内容写成一个文件。
  不注册账号、不访问任何云服务 API、不上传任何数据到我们这边。
- **只写你指定的那一个文件**。选择云盘目录时，应用仅判断该目录是否存在（不读取其他文件），
  手动导出落在 `<云盘目录>/JShell/jshell-sync-<日期>.jshellsync`。
- **自动同步是可选的主动行为**：开启后应用会在后台监听你选定的目录并在配置变化时写回
  （固定文件 `<目录>/JShell/jshell-auto.jshellsync`），频率受去抖控制，不会持续占用。
  关闭开关即完全停止读写该目录；同步口令用系统安全存储封装保存在
  `data/sync.json`，不会写进同步包，也不会通过界面接口回传。
- **同步位置可以是自己的服务器**（SFTP）：此时数据只在你与自己的服务器之间传输，
  不经过任何第三方；复用该主机的认证方式与跳板机设置，后台任务不会自行写入新的主机指纹。
  SFTP 没有变更通知，应用会每 15 秒读取一次该文件的修改时间与大小以判断是否需要同步。
- **也可以同步到 WebDAV**（Nextcloud / 坚果云 / 群晖等自选服务）：应用只用基础认证访问你填写的目录，
  仅执行 `HEAD` / `GET` / `PUT` / `MKCOL` / `DELETE`，不读取目录里的其它文件。
  WebDAV 密码与同步包口令分别保存、都经系统安全存储封装；地址强制 https（本机回环除外）。
- **内容由你勾选**：默认包含主机与分组、命令片段、偏好设置、端口转发；
  **默认不包含**密码与私钥口令、主机指纹；窗口尺寸、本机 shell 路径、开机自启等设备私有项永不导出。
- **加密由客户端完成**：选择口令后使用 `scrypt` 派生密钥并以 `AES-256-GCM` 整包加密，
  云盘服务商也只能看到密文。口令只用于本地加解密，不会上传；忘记口令即无法解密。
  未设置口令时同步包为明文，此时不允许勾选「密码与私钥口令」。
- 勾选「密码与私钥口令」时**强制要求加密**，应用不提供「明文携带密码」的选项。
- 导入与自动拉取前都会在 `data/backups/` 下自动备份当前配置，便于回退。

## 五、数据删除

- 卸载安装版后，手动删除数据目录即可彻底清除：macOS `~/Library/Application Support/JShell`，Windows `%APPDATA%\JShell`；
- 便携版直接删除整个程序目录即可；
- 在应用内删除主机时，会同时删除该主机保存的口令与公钥指纹记录。

## 六、权限说明

| 平台 | 权限 | 用途 |
| --- | --- | --- |
| macOS | 网络访问（出站） | SSH / SFTP |
| macOS | 登录项（可选） | 你开启「开机自动启动」时登记 |
| Windows | 当前用户启动项（可选） | 你开启「开机自动启动」时写入 |
| 两个平台 | 通知（可选） | 会话异常、传输失败提醒 |

应用不申请摄像头、麦克风、通讯录、定位、屏幕录制等权限。

## 七、变更与联系

隐私说明如有变更，会随版本更新记录（`CHANGELOG.md`）一并说明。内部渠道请联系分发人；公开渠道请通过发布页提供的联系方式反馈。
